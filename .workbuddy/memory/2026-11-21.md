## 修复 MySQL 目录迁移导致的硬编码路径失效
- 用户把 MySQL 文件夹从 `E:/AI-Agent/project/volunteer/MySQL/` 移到了 `E:/MySQL/mysql-26.10.0-winx64/mysql-26.10.0-winx64`，导致 3 处硬编码旧路径失效。
- 修复的 3 处：
  1. `deliverables/backend/start_mysql.bat` 第 3 行 `cd /d` 路径
  2. `deliverables/backend/start_server.bat` 第 5 行 `MYSQL_DIR` 变量
  3. `E:/MySQL/.../my.ini` 的 `basedir` + `datadir`（两行）
- 关键点：Python 代码（config.py/db.py）走 TCP 127.0.0.1:3306，与 MySQL 物理位置无关，无需改动；SQLite 兜底（qinghe.db + DB_ENGINE=sqlite）不受影响。
- 经验/坑：本机 Bash 命令在传递时会把反斜杠 `\` 自动转成正斜杠 `/`，导致字节替换匹配失败；改用 `chr(92)` 构造反斜杠字节、文件路径统一用正斜杠写即可规避。bat 文件为 GBK 编码，务必用二进制字节替换而非文本重写，否则中文会乱码。
